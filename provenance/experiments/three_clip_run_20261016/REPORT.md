原始碰撞网格也是代理几何，上述差异不能直接称为真实误碰撞。缺失几何还可能漏掉障碍，不能只依靠提高透明度阈值或缩小胶囊解决。

建议将实验拆成两种设置：固定可信碰撞代理 + 低质量视觉 PLY，用于比较探索策略；低质量视觉 PLY + 自身重建碰撞代理，用于测试包含碰撞误差的完整系统。前者需要明确声明评测使用代理几何，后者应另报受阻率、近零推进和可达区域差异。当前三段全程使用低质量碰撞 GLB，未中途更换。
