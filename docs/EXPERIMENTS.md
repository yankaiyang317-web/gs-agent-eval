# 已有验证与日常验证的区别

已有记录包括：核心CPU/GPU后端验证、三段81帧真实连续导航、完整128输入可靠性重建，以及GT RGB-D补几何+旧图回放的5组×2种子验证。历史报告/协议在provenance/experiments，完整模型和诊断仍在原machine25备份outputs。

GT补图第二段相对仅旧图继续重建，在固定薄弱区域有约+0.531dB PSNR净收益；重复视角仍可能有较高B，说明冗余未充分处理。样本是单场景少量轨迹，不作为普适有效性结论。RGB-only/视频大模型增强并未验证。

日常Agent消融：只跑探索→固定score→多次对照，无需重建。改评价机制时：先回归三段历史轨迹，换新协议后统一重算。研究B的预测能力时：再按固定训练预算做GT补图/增强对照，用独立空间留出视角测实际收益，不能用B本身证明B。

固定基准需要保留：代码版本/源码包、benchmark profile、benchmark_data状态包、对应场景PLY/GLB、每次run的轨迹与元数据及输出。大型模型/图片/视频存machine25或对象存储，不提交Git；Git只保存代码、协议、哈希和必要小样本。
