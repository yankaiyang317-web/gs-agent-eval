# 故居、老街重叠视角退化基线（2026-11-27）

这版用更多相邻、相互重叠的视角重新训练退化 PLY。高质量 PLY 和退化 PLY 一起下载，分别用于参考和 Agent 探索。旧版基线、旧评分状态与旧实验结果仍可从历史 Release 复现；新版使用新的场景名和 benchmark ID，不能把旧轨迹分数直接放进新版比较。

| 场景 | 新版合成训练图 | RGB 分辨率 | 深度分辨率 | 训练步数 | 最终高斯数 |
| --- | ---: | --- | --- | ---: | ---: |
| `guju_degraded_overlap` | 192 | 960×720 | 480×360 | 15,000 | 3,347,423 |
| `laojie_degraded_overlap` | 256（254 个唯一位姿） | 960×720 | 480×360 | 15,000 | 3,330,543 |

图像与相机位姿均来自各自高质量 PLY 的合成渲染，并非原始实拍或 COLMAP。训练从合成 RGB-D 种子开始，采用 gsplat 动态增点与裁剪，没有固定新增高斯上限。老街输入包含 192 张相邻路线视角和 64 张分散锚点视角；它们共同覆盖广场、店铺和桥亭。故居的 192 张来自相邻路线视角。

故居在训练后对一块建筑立面**明确删除了 14,601 个高斯**，形成局部残缺；这个缺口是受控后处理，不能写成少图训练自然形成。老街桥亭附近的模糊和残缺来自训练本身。主体路线仍可辨认，其他区域也保留重建误差与植被漂浮。

## 画面验收

先前留下的 32 个旧视角，与新版训练图有位姿重叠。按相机位置距离小于 0.4 且旋转差小于 20° 排除后，故居有 22 张、老街有 30 张可用于下表。PSNR 和深度误差只说明这些合成参考视角的重建保真度；未证明补拍后一定能修复。

| 场景 | 无近位姿重叠的旧留出图 | PSNR：旧 → 新 | 深度相对误差：旧 → 新 |
| --- | ---: | ---: | ---: |
| 故居 | 22 | 16.69 → 19.04 dB | 0.426 → 0.322 |
| 老街 | 30 | 18.89 → 20.46 dB | 0.429 → 0.168 |

逐视角结果、选图、相机位姿与训练协议随场景归档发布；96 个候选位置的四朝向路线预览保留在 machine25。合成训练输入图和辅助深度也暂留 machine25，未公开上传。老街 v1 的 PSNR 曾略有改善但大面积彩色漂浮仍然严重，因此没有作为新版；这里报告的是调整相机高度并补入重叠锚点后训练的 v2。

## 碰撞与运行

从两份新版 PLY 用 splattransform 3.1.6 生成了 0.12 场景单位分辨率的可选碰撞 GLB。胶囊碰撞检查显示，它们仍会阻碍部分候选路线，因此**默认运行配置使用各自高质量场景的固定碰撞 GLB**。这让视觉重建缺陷成为主要测试变量，也保持同场景不同 Agent 方法的碰撞条件相同；碰撞代理可能向 Agent 的移动反馈提供部分高质量几何信息，解释结果时须注明。

| 场景 | 碰撞 GLB | 96 个候选视角可站立 | 短距离相邻边可走 |
| --- | --- | ---: | ---: |
| 故居 | 默认固定网格 | 96 | 92/93 |
| 故居 | 新 PLY 生成网格 | 93 | 89/91 |
| 老街 | 默认固定网格 | 96 | 94/94 |
| 老街 | 新 PLY 生成网格 | 87 | 84/85 |

两份默认配置均已冷加载、起点渲染和碰撞检查。独立场景名是 `guju_degraded_overlap`、`laojie_degraded_overlap`；带 `_sparse_collision` 后缀的配置仅供碰撞消融测试。默认相机参数沿用 Agent 原配置的 320×240；训练输入保持 960×720。

## 固定评分状态

新的 A 参考域仍由各自高质量 PLY 的固定 160 个合成视角建立；缺陷权重对新版 PLY 重算。B 的可靠性证据只取这次训练所用的 RGB、辅助深度和由深度差分得到的法线，老街重复位姿不重复累计。状态与新低质量 PLY 的哈希绑定，已通过文件哈希、数组形状和有限值检查。

但可靠度落在 0.45–0.55 的高斯仍分别占故居 93.8%、老街 95.1%；当前 B 是**未验证预测有效性的固定原型**，不能解释为真实修复收益或直接跨场景比较。完全缺失高斯的区域也可能被 B 低估。此前两场景的 81 帧脚本视频和修复数字属于旧 PLY，不能作为新版成绩。新版 Agent 轨迹及补建验证需要重新录制和评分。
