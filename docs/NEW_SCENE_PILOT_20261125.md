# guju / laojie：固定评分、81 帧探索与补建试验

日期：2026-11-25。原始高质量 PLY、退化 PLY 和原 Agent 代码均保持不变。两个新评分状态分别绑定 `guju_degraded_full_inputs_v1` 与 `laojie_degraded_full_inputs_v2`；老街 v2 使用从原始起点相机图像上方向导出的世界竖直轴。

## 输入与状态

| 场景 | 退化重建实际训练图 | 留出图 | 固定 A 参考视角 | 低质量模型 Gaussian |
|---|---:|---:|---:|---:|
| guju | 64 | 32 | 160 | 400,000 |
| laojie | 128 | 32 | 160 | 400,000 |

每个场景的 160 张合成 RGB 为 1920×1440，辅助深度为 480×360，训练时 RGB 缩至 960×720。图像和相机位姿来自各自的高质量 PLY，并非原始实拍或 COLMAP。B 的 RGB、深度、深度差分法线误差只用实际训练图校准；32 张留出图不参与可靠性状态。A 用固定的高质量视角集合建立参考体素和缺陷权重。两场景的状态文件通过哈希、有限值、Gaussian 贡献守恒和训练/留出隔离检查。

## 两段脚本化探索

通过原项目 `SceneRuntime` 与 `EnvironmentTools` 的相同碰撞检查和帧记录接口，每场景各录制一段 960×720、81 帧、9 FPS 的覆盖探索。该轨迹由深度引导脚本选择移动和转向，用于验证完整链路；**不是千问或其他 LLM Agent 的自主探索结果**。两段视频均由 `ffprobe` 验证为 81 帧、960×720，均无跳跃或传送事件。

| 场景 | 导航动作 | 采样路径长度 | A：表面覆盖 @81 | B：固定视角价值均值 |
|---|---:|---:|---:|---:|
| guju_degraded | 18 | 10.16 场景单位 | 13.46% | 1.3931 |
| laojie_degraded | 15 | 12.00 场景单位 | 11.56% | 2.4737 |

两个场景的参考域不同，A/B 的原始数值不能跨场景直接排名。A 表示这条轨迹见到的不同参考体素比例；B 表示所拍帧对当前不可靠 Gaussian 的预测视角价值，不能单凭 B 推断真实补建增益。

## 用轨迹补建

从每条已录制轨迹按 B 值、首次覆盖和位姿间隔选 16 帧。使用对应**高质量 PLY**在这些精确位姿渲染 960×720 RGB 与 480×360 辅助深度。深度在低质量场景缺失或误差大的位置初始化 40,000 个新 Gaussian；原有 64/128 张训练图与新增 RGB 图共同用于 3000 步微调。输出独立的 `repaired.ply`，不覆盖原退化场景。与高质量 PLY 渲染图比较的 PSNR：

| 场景 | 16 个补拍训练视角：前 → 后 | 32 个未参与训练的留出视角：前 → 后 |
|---|---:|---:|
| guju | 16.17 → 24.05 dB（+7.89） | 16.78 → 17.13 dB（+0.35） |
| laojie | 21.24 → 27.30 dB（+6.06） | 18.91 → 18.98 dB（+0.07） |

两场景在**补拍位置附近**都有明显变化；未见过的 32 个视角只得到较小平均改善，尤其老街的 +0.07 dB 不足以证明全场景修复成功。这是一个局部、单条脚本轨迹的可行性试验。补拍位姿及伪 GT 深度均来自高质量 PLY，不能把结果解释成仅靠低质量视频恢复了缺失几何。后续若要检验 B 是否能选出真正有益的帧，应在同场景、同补图数量和同训练预算下比较 B 选帧与随机/覆盖选帧，并在未用于训练的视角报告结果。
